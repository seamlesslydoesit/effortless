# Pattern Parrot

Make repeating patterns on your phone. Pick a shape, choose colors, play with the layout, then save your pattern or download it as a picture (PNG) or a vector file (SVG).

## What's in the app

- **Start** – choose how the shapes are laid out (grid, half-drop, brick, mirrored, tossed, honeycomb) and the background color.
- **Shape** – 29 shapes in three sets: Basic, Advanced and Fun.
- **Details** – add a small second shape, choose filled or outlined, and pick how many shapes fit in a tile.
- **Colors** – the default colors, a random "Surprise Me!" palette, or make and name your own palettes.
- **Adjust** – size, spacing and rotation. On a phone you can also pinch and twist the preview with two fingers.
- **Save** – keep your pattern in My Patterns (you'll be asked to make a profile first).
- **Download** – a single tile or a 3 × 3 repeat, as a 2400 × 2400 PNG picture or an SVG file.

Your profile, patterns and palettes are kept on your own device, in your browser. There is no online account yet, so they won't move to another phone or computer.

Still to be written: the About, FAQ, Terms, Privacy and Help pages, and Mock ups. These show placeholder text in [brackets].

## Try it on your computer

You need [Node.js](https://nodejs.org) installed. Then, in this folder:

```
npm install
npm run dev
```

Open the web address it shows (usually http://localhost:5173).

## Put it online

The project includes a setup that publishes the app to GitHub Pages each time changes reach the `main` branch. Turn it on once in the GitHub repository: **Settings → Pages → Source → GitHub Actions**.
